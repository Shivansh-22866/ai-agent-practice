## For practice, making an agent for revision

## How to run

1. Create a Virtual Enviroment
```bash
python3 -m venv .flight-agent
```

2. Activate the said environment
```bash
source .flight-agent/bin/activate
```

3. Install requirements
```bash
pip install -r requirements.txt
```

4. Create the environment file
```bash
cp .env.example .env
```
